# ADR-0005 — The craft tier admits operating discipline, not prose alone

The craft tier began as prose style with no external standard behind it. A
proposed skill on agent narration raised the boundary question: is a rule
about how an agent works, rather than how it writes, in scope?

**Decision.** The craft tier admits operating discipline. The authority is
still ours, each skill still says so, and the measurement bar is the same.

**Consequences.** The bench must eventually drive multi-step agentic work,
which the current runner cannot. Until it does, no operating-discipline rule
claims measured effect. The measurement design defers this in its final
section.
