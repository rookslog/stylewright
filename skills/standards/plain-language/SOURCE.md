## A note on the canonical URL

The original site at `plainlanguage.gov` returns HTTP 301 to
`digital.gov/guides/plain-language`. That page carries a curated subset and
states no license.

The archived repository above is therefore the source of record. It holds the
full guideline set, one page per guideline, and it states the license.

## How to re-check this record

1. Open `https://github.com/GSA/plainlanguage.gov/blob/master/LICENSE.md`.
2. Confirm the CC0 dedication and the United States Government statement.
3. List the guidelines with the command in the grounding matrix.

## Why a CC0 source still gets a paraphrase

CC0 permits copying. Our doctrine still requires our own words, so that every
skill reads consistently and so that the grounding matrix means the same thing
in every skill.
